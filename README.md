# WOOF

個人 AI agent 桌面程式。核心很小，模型、工具、記憶都是 `plugins/` 底下的插件。

## 下載（不用裝 Python、Node）

到 **[Releases](https://github.com/BBQ2077/WOOF-AGENT/releases)** 下載兩個 zip，**解壓到同一個資料夾**：

| 檔案 | 內容 | 什麼時候要重新下載 |
|---|---|---|
| `WOOF-A-runtime-*.zip` | 執行環境：`python\`（Python 3.14 與所有套件）、`release\WOOF-win32-x64\`（桌面外殼） | 很少；只有 Python、套件或 Electron 升級時 |
| `WOOF-B-app-*.zip` | 程式本體：`woof\`、`plugins\`、`web\` 等，與本倉庫同一版 | 每次更新 |

更新時通常只要下載新的 B 包覆蓋舊檔；Release 說明會寫要搭配哪一版 A 包。你的對話、設定、金鑰都在 `data\`、`config.toml`、`keys.toml`，B 包裡沒有這些，覆蓋不會動到。

也可以用 `git clone` 代替 B 包，再把 A 包解壓進 clone 下來的資料夾（`python/`、`release/` 已在 `.gitignore`），之後用 `git pull` 更新。

需要 Windows 10／11 64 位元。終端機工具用 Git Bash，請先裝 [Git for Windows](https://git-scm.com/download/win)。

## 開啟

雙擊 `WOOF.vbs`（或 `release\WOOF-win32-x64\WOOF.exe`，可以釘到工作列）。第一次開啟到「設定 → 服務商」填 API key。關掉視窗會縮到系統匣；要完全結束，在系統匣圖示按右鍵 →「結束 WOOF」，後端和它開的所有程序會一起關掉。

## 從原始碼安裝

```bash
# Python 後端
uv sync                                  # 依 pyproject.toml 建 .venv 並安裝相依套件

# Electron 外殼
cd desktop
npm install
node node_modules/electron/install.js   # 新版 npm 不會自動跑這步，Electron 本體要手動下載
```

## 在另一台電腦跑

後端可以跑在別台電腦（家裡主機、雲端主機、WSL），本機桌面程式或手機瀏覽器連過去用。那台電腦開著，排程才會繼續跑。

預設只聽本機，什麼都不用改。要開放，在那台電腦的 `config.toml` 加一節：

```toml
[server]
bind = "lan"          # lan＝區網；public＝外網
```

開放之前先設登入密碼（只存雜湊，不留明文）：

```bash
.venv/Scripts/python -m woof set-password
```

再啟動後端，`--port` 不填就隨機挑一個，遠端連線建議固定：

```bash
.venv/Scripts/python -m woof --port 8000
```

- 區網（`bind = "lan"`）：綁 `0.0.0.0`，同一個網路的手機、筆電用 `http://<那台的 IP>:8000` 開。Windows 第一次會問防火牆，要允許。
- 外網（`bind = "public"`）：一定要 HTTPS，兩種做法挑一種。直接給憑證就把 `https_cert`、`https_key` 填 PEM 檔路徑；放在 Caddy、nginx 之類的反向代理後面就設 `trust_proxy = true`。沒設好會拒絕對外開放，啟動時印出原因就結束。

登入：第一次開啟會問密碼，過了發一張有期限的憑證（預設 30 天，`session_days` 可改）給那個瀏覽器；過期或換裝置再登入一次。同一個來源連續打錯 8 次鎖 5 分鐘。

連過去的方式：

- 桌面版：「設定 → 連線 → 連線到…」填遠端位址，例如 `https://woof.example.com`。填了就不會啟動本機後端，清空就回本機。
- 手機或另一台電腦：瀏覽器直接開那個網址，不用裝桌面程式。

開放之後，能連到那個位址又有密碼的人就能用你的 WOOF：讀寫檔案、執行指令、花你的 API 額度，只給自己用。簽章用的金鑰在 `data/server_secret`，備份要帶走；刪掉它等於所有裝置都要重新登入。

## 設定檔

| 檔案 | 內容 |
|---|---|
| `config.toml` | 模型商、模型、工作目錄、允許預覽的資料夾、權限 |
| `keys.toml` | API key；同一個金鑰池可放多把，額度用完或被擋會自動換下一把 |
| `plugins/<名稱>/plugin.toml` | 插件說明和設定欄位，介面的設定表單由這裡自動產生 |

平常直接在「設定」頁改，按「儲存變更」生效。手動改檔後到「插件」頁按「重新載入」。外觀（顏色、縮放、字級）存在介面本機，不寫進設定檔。

### 多組設定（profile）

想要分開的幾套 WOOF（例如工作、私人）就用設定組：每一組都有**自己的** `config.toml`、`keys.toml` 和 `data/`——
金鑰、模型、記憶、Skills、對話、排程紀錄全部各自獨立，不會互相看到。

| 設定組 | 位置 |
|---|---|
| 預設 | 專案本來的 `config.toml`、`keys.toml`、`data/`（不動它） |
| 其他 | `data/profiles/<id>/config.toml`、`keys.toml`、`data/` |

清單存在 `data/profiles.json`（所有組共用）：`{version, last, profiles: [{id, name, created}]}`。

在左側選單最下面的**設定組**那一列切換：點一下列出所有組、可以新增、改名、刪除，目前這組前面有勾。
切換會重啟 WOOF（後端啟動時就把資料路徑決定了，所以沒辦法不重新啟動）；刪除某一組會把它的 `config.toml`、
`keys.toml`、`data/` 整個刪掉，無法復原，所以目前正在用的那一組不能刪，要先切到別組。

是怎麼認的：後端啟動時讀環境變數 `WOOF_PROFILE`，`default` 或沒設就是預設那組；不在清單裡的代號也會退回預設。
Electron 主程式會把目前這組寫進 `WOOF_PROFILE` 再啟動 Python，切換時換掉它、重啟後端、重載視窗。
用瀏覽器開介面時沒有人能重啟後端，這時只會把「下次啟動用哪一組」記下來，重開 WOOF 才生效。

介面偏好（配色、我的最愛、思考強度）也跟著設定組走，存在該組 `data/ui-preferences.json`。

### 模型商與模型

模型商放連線方式和共用欄位，模型只放自己的名稱與能力；模型自己寫的同名欄位會蓋過模型商的。

```toml
[[vendors]]
id = "openrouter"                  # 代號，模型用 vendor 對應
label = "OpenRouter"               # 介面顯示名稱
provider = "openai_compat"         # 用哪個插件：openai_compat / anthropic / claude_cli
base_url = "https://openrouter.ai/api/v1"
key_pool = "openrouter"            # 對應 keys.toml 的 [[openrouter]]
effort_style = "openrouter"        # 思考強度參數格式：none / openai / deepseek / openrouter
rate_limit_wait = 120              # 被 429 限流時最多等幾秒重試

[[models]]
id = "gemma4-31b-free"             # 內部代號
vendor = "openrouter"
label = "Gemma 4 31B（免費）"
model = "google/gemma-4-31b-it:free"
efforts = []                       # 介面上可選的思考強度
vision = true
context_window = 262144
price = [0.5, 1.5, 0.05]           # 選填：美元／每百萬 token，輸入 / 輸出 / 快取讀取；用量面板據此算金額
```

「花費與預算」預設關閉，在「設定 → 一般」打開；打開後右側「額度」會顯示金額與預算卡、模型表多一欄單價，並可設每日、每月上限，超過時可選只提醒、暫停送出，或改用「模型用途 → 備用模型」。沒填單價的模型不算錢。

主要模型出錯（限流、額度用完、連不上，服務商自己的重試都用完）時，如果設了備用模型，這一回合改用它接著做，做到一半也會接手，前面的工具結果都保留。備用模型在「模型用途」裡自己一區，預設不設，也不受「全部跟隨主模型」影響：不設就直接停下來告訴你，比換一個不熟的模型接著做安全。

GPT 類推理模型（gpt-5、gpt-6、o 系列）在官方 OpenAI 端點預設走 Responses API（POST /responses）：思考強度用 reasoning.effort，思考摘要會在多輪與工具呼叫之間保留，工具呼叫走 function_call／function_call_output。其他相容服務商照舊走 Chat Completions。

要固定某個模型商或模型走哪一種，在那一層寫 api_style = "chat" 或 "responses"（模型寫的蓋過模型商的；都沒寫就照上面的規則自動判斷）。介面上在模型商展開後有「API 介面」可選，模型的設定檔欄位也吃這個值。

## 連接 Claude

WOOF 不提供 Claude 帳號登入，有兩種用法：

| 方式 | 設定 | 計費 |
|---|---|---|
| Anthropic API | `provider = "anthropic"`，`keys.toml` 放 Claude Console 的 API key | 依 API 用量計費 |
| 本機 Claude Code | `provider = "claude_cli"`，WOOF 呼叫你電腦上原版的 `claude` 指令 | 依你在 Claude Code 裡登入的方式；WOOF 不讀、不存任何 Claude 憑證 |

用本機 Claude Code 前，先自己安裝並執行 `claude auth login`。

## 介面語言

「設定 → 外觀 → 介面語言」可切換繁體中文與 English。切換後，模型的基礎提示詞與回覆語言會一起改；進行中的對話會在下一則訊息附上語言變更，不重組系統提示詞。

## 模式預設組

把「哪些插件可用」和「工具權限」打包成一個模式，一鍵套用。適合在不同用途之間切換：一般聊天、寫作創作、動手做專案、統籌型工作、只查不改。

| 模式 | 權限 | 插件 |
|---|---|---|
| 一般聊天 | 先問我 | 讀檔、記憶、網搜、看圖等；不給終端機和子代理 |
| 寫作創作 | 改檔自動 | 留著網搜和看圖，可以邊查邊寫；跑指令、連網先問 |
| 動手做 | 全自動 | 全部開放，適合把整個專案交給它做 |
| 統籌 | 改檔自動 | 以子代理為主，自己不動手 |
| 只查不改 | 唯讀 | 只能讀和搜尋，寫檔、跑指令一律擋下 |

套用範圍分兩種：

- **目前對話**：權限下一則訊息就換；插件開關排到下次壓縮或開新對話才換。中途換插件會讓這個對話的系統提示詞重組、模型的前綴快取整段失效，所以改成排隊，等本來就要重組的那一次再一次套用。
- **新對話預設**：在「設定 → 模式預設組」指定哪一個當預設，開新對話時自動套用。

自訂的模式存在 `data/presets.json`（不寫進 `config.toml`）。內建的不能改也不能刪，要改就另存一個新的。在對話的「插件」面板也可以直接選模式套用。

## 同時開幾個對話

對話清單上方有一列分頁，同一個視窗可以開最多 4 個對話，用滑鼠點分頁切換，按分頁右上的 × 關掉。

- 側邊欄按住 Ctrl 或 Cmd 點對話，會另開一個分頁，不必把目前這個換掉。
- 分頁列最右邊的「＋」開一個新的空白分頁；Ctrl N 一樣。
- 每個分頁各自記住自己的訊息、捲動位置、輸入框草稿與權限設定，切來切去不會互相干擾。
- 串流、工具卡、插話、停止、右側面板（檔案樹、TODO、額度、終端機）一律作用在目前這個分頁，背景分頁的訊息照樣累積，切回去就看得到。
- 開了哪些分頁、目前停在哪一個，重開程式後會照原樣還原。
- 分頁列最右邊的並排鈕，把另一個對話開在右半邊，兩邊各有自己的輸入框、串流與停止鍵；右半邊是同一支介面的獨立畫面，關掉它左邊完全不受影響。

## 對話分群

對話多的時候可以分群組，像「TODO」這種同一件事的多個對話就放同一群。

- 側欄「對話」右邊的「＋ 群組」建一個新群組，點群組標題可以收合。
- 把對話拖到群組標題上就搬進去；拖到「未分組」就搬出來。
- 群組標題右邊的「⋯」可以改名或刪除。
- 刪群組一定會問兩次：第一次確認要刪，第二次才問「連對話一起刪掉」還是「只刪群組」。選前者，群組裡（含子代理）的對話一起消失；選後者，對話回到未分組。

子代理不會跟一般對話混在一起，掛在叫它的那個對話底下，分成兩疊：

- **子代理**：同一次派出的算一批（「第 1 批 · 3 個」），每批可以各自收合；只有一批時直接列出來。最新一批預設展開。
- **審核**：審核模型、拓展模型自成一疊（✓ 審核 N 個），長任務來回審幾十次也不會淹掉子代理。

生圖、生影片也走子代理：主模型呼叫 `delegate_task` 時 `model` 填 `image` 或 `video`（漏填但 goal 開頭就是「生成一張圖」也算），不開子對話，直接交給生圖或影片模型，回傳檔案；`scope` 給資料夾就另存一份。這樣 `image_generate`／`video_generate` 兩個工具可以關著，不用每輪多送它們的說明。用哪個模型在「設定 → 模型用途 → 生圖・生影片」選（只列生圖或影片模型，換哪家都行）；留空就用第一個有 key 的。主模型直接點名某個生成模型時以點名的為準。生圖、影片模型不能當預設子代理（它們不會跑工具）。
- 疊與批的標題右邊有 ×，一次刪掉整疊或整批（只刪子代理，主對話不動）。
- 想留某個子代理，把它拖到群組標題（沒有群組時拖到日期標題）上，就拆成獨立對話。
- 有子代理或審核還在跑時，標題列會寫「N 個在跑」並閃燈，主對話那一列也跟著閃。

群組與對話的歸屬記在 `data/woof.db`，跟著那一組設定走。


## 寵物

右側「寵物」分頁住著陪你說話的角色，不是助理。內建兩個：**沃夫**（Woof，黃金獵犬，可愛黏人、很容易被零食收買，句尾常帶「汪」）與**大肥魚**（DeepSeek 藍鯨女僕，慵懶、愛吃白飯、自稱「本魚」，卡住會先喊「全給爆了」再給偷懶的鬼點子）。在「設定 → 寵物 → 角色」切換，兩邊的對話、記憶、檔案完全分開。

版面由上而下：對話紀錄 → 頭頂泡泡（牠最新的一則）→ 牠 → 一顆模型建議 → 固定回覆 → 輸入框。

- **講話像傳訊息**：回多長跟著你這句走。你回「好」「哈哈」，牠多半只按個表情不說話；平常一兩句；你問牠想法才講兩三則。想講兩件事就連發兩則，泡泡會一則一則冒出來，中間有打字中的小點點。
- **雙方都能按表情**：滑到牠的訊息旁邊點 ☺，或直接雙擊那則（等於按 ❤️）。表情列是 ❤️ 😂 🥺 👍 😮 🔥 😴，再加角色的招牌（沃夫 🐾、大肥魚 🍚）；同一個再按一次就收回。牠會馬上換表情，下一句也看得到你按了什麼。牠也會對你的話按表情，按什麼看你說了什麼，不會每次都同一個。
- **一顆模型建議＋固定回覆**：輸入框上面那顆整排寬的是模型猜你最可能回的一句（會變）；下面是固定的通用回覆（預設「怎麼了？」「繼續說」，在「設定 → 寵物 → 固定回覆」改，用 | 分隔，最多四個）。點了直接送出。
- **輸入框可以打多行**：Enter 送出、Shift+Enter 換行；文字長會自己長高（最多約五行）。
- **自己的對話窗**：訊息、提示詞、記憶、壓縮全部跟你的對話分開。你的對話不會因為牠變長，快取也不會被牠打斷。
- **摸摸牠**：點牠的圖就是摸頭，連點幾下算一次（紀錄裡會寫「你摸了牠 3 下」），牠會回一句。
- **三種模式**（寵物欄右上 ⋯ 或「設定 → 寵物」切換，標頭會顯示目前是哪一種）：
  - **情感**：不看你的對話，單純陪你聊；你跟牠講話時，牠也不會拿你的工作內容來接。
  - **混合**（預設）：看著你的對話，有新東西時說一句，也會聊心情。
  - **工作**：看著你的對話，只聊手上的事（進度、卡在哪、該不該休息）；不撒嬌、不聊感情，口頭禪和個性照舊。
- **看對話開口**：混合、工作模式下，背景每 10 秒（可設 3～120 秒）瞄一眼你開著的對話，有新回覆才叫模型，沒有新內容不花錢。
- **看時間找你**：像 Nomi、Replika 那種「AI 先傳訊息給你」。你一陣子沒找牠，或換到早上、中午、晚上而你們這個時段還沒講過話，牠會自己傳一句，優先接你之前提過、還沒下文的事（「面試準備好了沒～」），不發「在嗎」這種空招呼。
  - 頻率四段：不找／很少（沉默 12 小時、一天最多 1 次）／偶爾（3 小時、一天 4 次，預設）／常常（1 小時、一天 8 次）。
  - 每多一則你沒回，間隔加倍；連續三則沒回就不再找，等你先開口。剛聊過不插話。
  - 安靜時段預設 23 點到隔天 8 點，這段時間不會看時間找你；你還在用時，看對話照樣會說。
  - 牠覺得沒什麼好講可以不講，過半個鐘頭以上才再想一次；講過的話會給牠看，不會一字不差重複。
  - 紀錄裡隔超過 30 分鐘的訊息之間會標時間，牠主動找你的那則會寫「牠主動找你」。
- **主動說話可以關**：關掉後牠不看對話、也不看時間找你；你打字或摸牠，牠照樣回。
- **按表情的頻率**：「不按／偶爾／常常」三段。你只回「好」「哈哈」時牠只按表情不說話，這種不受限。
- **看得很少**：預設只讀主對話最近約 1,500 tokens（可調），不是整份。牠不知道的事會說不知道。
- **自己的模型**：預設 DeepSeek V4.1 Flash（便宜、快），跟主對話用的模型無關。設定頁跟主對話一樣先選服務商、再選模型；不選就自動挑一個便宜的。思考（不用／想一下）與每次輸出長度分開設定。
- **設定頁的數字**：都是拉桿加數字框，兩邊同步；改了直接存，說明文字跟著換成新數字，頁面不會跳回頂端。
- **自己的記憶**：`data/pet/chat-<角色>.json`，上限預設 30,000 tokens，超過八成自己壓成幾行筆記，留最近 12 則原文。這組壓縮跟「設定 → 上下文壓縮」完全無關。
- **自己的檔**：`data/pet/chars/<角色>.md` 只寫「牠是誰」（檔案、喜歡、討厭、小毛病、口頭禪、語氣、示範）；怎麼聊（長度、連發、按表情、輸出格式）是所有角色共用的規則，寫在程式裡，換角色或自己寫新角色都不用重寫。沒改過的檔會跟著新版預設更新；改過的就不會動。
- **只用繁體**：模型偶爾漏出的簡體字會在顯示前轉成台灣用字。
- **16 張表情圖**：`web/dist/pet/<角色>/<表情>.webp`，代號固定（happy、laugh、comfort、sleepy…），模型每次回覆會自己挑一個、也會自己填「心情」兩個字。想換成自己的圖就放到 `data/pet/sprites/chars/<角色>/`，同代號會蓋過內建的；之後要換 3D 模型，只要換這一層。
- **要不要在主對話留言**：預設關。打開後牠講的話會以牠的招牌表情開頭，出現在你的對話裡。
- **右上 ⋯**：看一眼、編輯寵物檔、清空牠的記憶、跳到寵物設定。
- **預設唯讀**：牠沒有工具、不能改檔案、也不能把話寫進你的對話。想讓牠留言，要自己去「設定 → 寵物」把「在主對話留言」打開。
- **不進主提示詞**：主模型看不到牠、也不能呼叫牠，所以不會多花 token，也不會影響工具權限。

## 對話區的小功能

- **右鍵**：選了字就有「複製」「引用到輸入框」；在訊息上有「複製這則訊息」；程式碼區塊有「複製程式碼」；圖片有「複製圖片」「看大圖」「圖片另存為…」「複製圖片路徑」；連結有「開啟連結」「複製連結」。
- **連結**：網址點了用系統瀏覽器開。回覆裡提到的本機路徑（`C:\…`、`C:/…`、`/c/…`，也包含整段是路徑的行內程式碼）會變成連結：點一下在右側預覽（圖片用看圖器），右鍵可以用預設程式開或在資料夾中顯示。
- **往上看東西不會被拉走**：點開內部指令、思考、工具輸出，或往上捲，就停止自動捲到底；模型回話、重畫時畫面和框內的捲動位置都留在原處。按右下的 ↓ 或自己捲回底部才恢復跟隨。
- **背景還在跑的提示**：主對話沒在出字、但它或底下的子代理／審核還在跑時，輸入框上方會有一行「還在跑：…」，寫著最近一個動作和「N 秒前有動靜」，不會以為卡住。

## 安全預設值

WOOF 讓模型在你的電腦上讀寫檔案、執行指令。下面是沒改設定時的行為：

| 項目 | 預設 |
|---|---|
| 後端連線 | 只聽 `127.0.0.1`，埠號隨機，每次啟動產生新的存取 token，沒有 token 的請求一律拒絕。要開放區網或外網得自己改 `[server]`：先設登入密碼，外網還要求 HTTPS，沒設好會拒絕啟動 |
| API key | `keys.toml` 用 Windows DPAPI 加密，只有同一台電腦、同一個 Windows 帳號解得開 |
| 工具輸出 | 送進模型、存進對話、顯示在畫面前，會遮掉 `keys.toml` 裡的 key 和常見格式的金鑰（`redact_secrets = false` 可關） |
| 新對話的權限 | 「先問我」：讀檔、搜尋、連網直接做；寫檔、執行指令、子代理、MCP 工具先問你 |
| 危險指令 | 在會自動執行的模式裡仍先問（`rm -rf`、`git push --force`、格式化等）；刪整顆磁碟、fork bomb 等任何模式都擋 |
| 排程的對話 | 沒人能按允許，要先問的工具直接擋下 |
| 自動審核 | 預設關閉。在「設定 → 模型用途 → 自動審核」指定模型後，要先問你的動作會先交給它判斷，判定安全就放行並在對話裡留一行紀錄；送過去的只有工具名稱、參數和工作目錄。危險指令一律問你 |
| 生成速度 | 每則回覆底下顯示「模型 · XX tok/s · 填充 X.Xs · 時間」：tok/s＝輸出 token（含思考）÷ 生成時間；填充＝送出到第一個字的時間（模型讀上下文），多步加總。滑鼠移上去列出每一步 |
| 方案模式的上限 | 「設定 → 方案模式」：方案最多提幾版（預設 3）、做完驗收後最多補幾輪（預設 1）、每次審核／拓展最多等多久（預設 300 秒，超過就照目前這版繼續），不會無限打回。同一頁可以改審核、拓展、規劃的提示詞。`/goal` 預設照對話選的方案模式走，打回到上限或你沒回應時照最後一版做，不停下來等 |
| 提問等多久 | 模型用提問卡片問你時，180 秒沒回就自動略過，告訴模型你可能不在、讓它自己判斷繼續，刪檔、覆蓋、對外發送這類收不回來的事留到最後再問。卡片上有倒數，在卡片上打字會重新計時。「設定 → 權限 → 問你問題時等多久」可調，0＝一直等 |
| 模型能不能看圖 | 「設定 → 模型商」每個模型的看圖選「自動／能看／不能看」。自動（預設）：不看模型商目錄寫的輸入類型（目錄常寫錯），先把圖直接送給模型，被拒絕才記下來、改交給「輔助模型 → 看圖」轉成文字，選單會顯示「自動·不能」。判斷錯了就改成「能看」，手動設定蓋過自動偵測 |
| 寫入型子代理 | 只能改主代理指定範圍內的檔案；可以跑 terminal 驗證，但工作目錄限在範圍內、不能開背景指令 |
| 檔案還原 | 模型用 `write_file`／`patch` 改檔前會先備份，可還原到任一則訊息之前；終端機指令改的檔追不到 |

使用前要知道的事：

- 讀檔沒有限制資料夾，模型讀得到你這個 Windows 帳號讀得到的所有檔案。
- 對話紀錄存在 `data/woof.db`，沒有加密。
- 網頁搜尋與擷取透過 Firecrawl、Tavily 的雲端服務，查詢字串和網址會送給它們；擷取在它們的伺服器上進行，連不到你的區域網路。
- 你傳的訊息、圖片和工具結果會送給你選的模型商。
- 權限可在「設定 → 權限」或 `config.toml` 的 `[permissions]` 調整（範例見 `config.example.toml`）。改成「全自動」後，模型不經確認就能寫檔和執行指令。

## 新增插件

複製 `plugins/_template`，改資料夾名稱和 `plugin.toml`，寫 `__init__.py` 的 `register(woof)`，到介面「插件」頁按「重新載入」。

## 結構

```
woof/          核心：設定、資料庫、程序管理、插件載入、工具迴圈、伺服器
plugins/       所有功能
desktop/       Electron 外殼（main.js、preload.js）
web/dist/      介面（index.html、app.js、app.css）
data/          預設那組：對話資料庫、日誌、上傳的圖片、排程
data/profiles/ 其他設定組（各有一組 config.toml、keys.toml、data/）
tests/         測試腳本（`.venv/Scripts/python tests/unit_test.py` 跑單元測試，用暫存資料夾，不碰你的對話）
```

### 測試與評測

```
.venv/Scripts/python tests/unit_test.py            # 純函式單元測試（排程、快照、權限、思考強度）
.venv/Scripts/python tests/eval_test.py            # 評測：假模型跑 20 題小任務，自動判分
.venv/Scripts/python tests/eval_test.py --only sub_read,compact_continue
.venv/Scripts/python tests/eval_test.py --model <模型 id>   # 換模型跑同一批題目
.venv/Scripts/python tests/eval_test.py --model nvidia-nemotron-lightning --limit 3   # 真模型跑前 3 題
```

評測在暫存資料夾裡開一個乾淨的 WOOF_DATA，只載入 files、terminal、tasks、subagent、context 這幾個插件，
用腳本化的假模型跑題庫，逐題檢查工具呼叫、檔案結果、權限擋下、子代理、背景指令與壓縮後續作。
結果寫進 `data/eval/`（已被 .gitignore 忽略），JSON 與 Markdown 各一份，方便改提示詞或插件前後比較。

真模型模式（`--model` 給 config.toml 裡的模型 id）會讀本體的 `config.toml`（副本沒有時可用 `--config-root` 指定），工作目錄換成暫存資料夾，金鑰從 `keys.toml` 在記憶體裡解開，不寫暫存檔也不印出來；模型與輔助模型都指向同一個模型，所以會真的花 token。預設跳過只有腳本假模型才做得出來的題目（參數被截斷、同一個失敗重複三次、找不到工具），要全跑加 `--all`；每題有 `--timeout` 秒上限（預設 180）。報告另記模型 id、工具步數、token、耗時與失敗原因。


## 內建插件

| 插件 | 做什麼 | 設定 |
|---|---|---|
| `web_search` | 網路搜尋與網頁擷取，Firecrawl 與 Tavily 多把 key 輪換 | `keys.toml` 的 `[[firecrawl]]`、`[[tavily]]`；用完的 key 標到下個月 1 日自動恢復 |
| `context` | 上下文用量超過「壓縮門檻」（預設 70%）時，先把較早、用過的工具輸出換成一行佔位；這樣還不夠才把較早的訊息寫成摘要，之後只送摘要加最近幾輪 | 插件設定可改壓縮門檻與保留輪數 |
| `vision` | 讓 agent 看本機圖片檔（`vision_analyze`） | 空白則用目前對話的模型，不支援看圖時改用清單裡第一個支援的 |
| `focus` | 重點便條，**預設關閉**。打開後只在上下文剛壓縮完的下一次請求，於最後面補一次待辦進度、權限、最近出錯、改過的檔 | 有些模型看到便條會把同一件事重想一遍，長任務在原地打轉時保持關閉；模式預設組不會自動打開它 |
| `mcp_client` | 連接 MCP 伺服器，對方的工具以 `mcp_<名稱>_<工具>` 提供 | 設定每行一個：`名稱 \| command 參數` 或 `名稱 \| http://位址` |

MCP 連線在第一次對話時建立，插件重載或後端結束時關閉。stdio 子程序由 SDK 放進 Job Object，後端被殺會一起結束。
